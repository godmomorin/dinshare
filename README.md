# DinShare 🎬🎵🎙

誰でも投稿できるメディア共有サイト（動画・写真・音声・音楽・テキスト）

## 機能

- 📝 テキスト / 🖼 写真 / 🎬 動画 / 🎙 Voice / 🎵 Music の投稿
- 👤 アカウント機能（**メールアドレス不要**、ユーザーネーム＋パスワードのみ）
- 🗑 自分の投稿だけ削除できる（本人確認はログインで行う）
- 🔥 高評価 ＆ 👍 ちょっと好きボタン（何回でも押せる）
- 💬 コメント機能（**絵文字を3種類以上使わないと送信できない**ルール付き）
- 🔍 検索機能
- ▶ 動画・音声の自動連続再生＋関連コンテンツ表示
- 📋 プレイリスト作成・再生

## セットアップ手順（Windows）

### 1. このフォルダを好きな場所に置く

例: `C:\Users\あなたの名前\dinshare`

### 2. PowerShellを開いてフォルダに移動

```powershell
cd C:\Users\あなたの名前\dinshare
```

### 3. 必要なライブラリをインストール（初回のみ）

```powershell
npm install
```

※ 数分かかることがあります。

### 4. サーバーを起動

```powershell
npm start
```

「🚀 DinShare サーバー起動: http://localhost:3000」と表示されたら成功！

### 5. ブラウザで開く

http://localhost:3000 にアクセス

## スマホから使うには（同じWi-Fi内）

1. PowerShellで `ipconfig` と入力し、「IPv4 アドレス」を確認（例: 192.168.1.5）
2. スマホのブラウザで `http://192.168.1.5:3000` にアクセス

※ PCとスマホが同じWi-Fiに接続されている必要があります。
※ Windowsファイアウォールの確認画面が出たら「アクセスを許可」してください。

## データの保存場所

- 投稿・アカウント情報: `dinshare.db`（SQLiteデータベース）
- アップロードされたファイル: `uploads/` フォルダ

この2つをバックアップすればデータを保全できます。

## インターネットに公開するには

このままではローカル（自宅ネットワーク内）でしか使えません。
インターネット公開には以下のようなサービスへのデプロイが必要です：

- **Render** (https://render.com) — 無料プランあり、初心者向け
- **Railway** (https://railway.app) — 簡単デプロイ
- **VPS**（ConoHa、さくらVPSなど）— 自由度が高い

※ 公開する場合は、HTTPS化・ファイルサイズ制限・不適切コンテンツ対策などの
セキュリティ対応を追加することを強くおすすめします。

## 注意事項

- パスワードはbcryptでハッシュ化して保存されます（平文保存ではありません）
- パスワードを忘れた場合の復旧機能はありません（メアド登録がないため）
- ファイルアップロード上限は200MBです（server.jsで変更可能）
